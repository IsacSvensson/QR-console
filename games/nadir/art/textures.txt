# NADIR wall materials (DESIGN.md §3.6). 32 x 32 texels each, u left to right, v top to bottom.
#
#   material <map char> <name>          starts a material; its id is its position in this file (1, 2, ...)
#   legend <char> <colour>[!] ...       colour 0-15; '!' = emissive (index + 16, not darkened by fog)
#   band <v> [<u0> <u1>]                row v is drawn as a perspective-correct vector line (u0..u1 exclusive)
#   seam <u>                            column u is drawn as a vertical vector line
#   scroll <shift>                      u-scroll: the texture moves one column every 2^shift frames
#   frame                               starts the next animation frame (same legend, bands may differ)
#   anim <shift>                        frames change every 2^shift frames
#   procedural rock <seed>              rows generated by tools/textures.ts
#   rows ... end                        32 rows of 32 characters
#
# Budget rule (DESIGN §9): on average at most ~2.5 colour runs per column besides the base colour, so broad
# horizontal structure is either the base colour or a band, and fine vertical structure sits in few columns.
