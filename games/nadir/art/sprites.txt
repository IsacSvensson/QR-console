# NADIR sprites (DESIGN.md §3.12): props and pickups, drawn as lists of rectangles (tools/sprites.ts).
#
#   sprite <map char> <name> <width> <height>   starts a sprite (at most 16 x 24 source pixels; map char - = an
#                                               animation frame, not placed in a map)
#   sprite <map char> <name> box                a 3D box instead (DESIGN §3.12): no rows; its footprint is the block
#   box <face> <lid> <lines> <style>            box colours (0-15, ! = emissive) and style: 0 crate (frame, cross
#                                               brace), 1 console (an emissive screen on every side)
#   height <percent>                            its height as a percentage of the wall height (it stands on the floor)
#   block <half>                                half-size of its blocking box in u8.8 (0 = the player walks through)
#   pick <kind>                                 0 = not a pickup, 1 = medkit, 2 = ammunition
#   legend <char> <colour>[!] ...               as in textures.txt; t = transparent
#   rows ... end
#
# Rule for 128 x 128: broad shapes and few colour changes, so that LOD 0 stays within 48 rectangles.
